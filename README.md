# Digitrust Solutions

Official website for Digitrust Solutions, a Gurugram-based digital agency specialising in web development, social media, SEO, Meta advertising, and full-stack development.

## Stack

- Next.js 16 with the App Router
- React 19 and TypeScript
- MongoDB Atlas for website enquiries
- Tailwind CSS 4 foundation with a custom responsive design system

## Local development

1. Copy `.env.example` to `.env.local` and add the required values.
2. Install dependencies with `npm install`.
3. Start the local site with `npm run dev`.

The enquiry form writes to the `website_enquiries` collection in the configured MongoDB database.
